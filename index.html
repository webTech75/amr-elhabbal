About me

I'm a web developer with 13 years of experience building fast, accessible, and responsive applications for organizations including JPMorgan Chase, Toyota, and Cricket Wireless. I care about clean, maintainable code and interfaces that people enjoy using.

My focus today is full-stack AI. I designed and built Neura, an AI software engineering assistant with a Python and FastAPI backend, JWT authentication, and a secure tool system that lets an LLM work with real project files. A React and TypeScript front end completes the product, bringing the same attention to craft that I've applied to user interfaces throughout my career.
